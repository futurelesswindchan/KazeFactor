> 🚧 **项目状态**: 架构设计与基础设施搭建中

一个开源的 Android 自动化工具，帮助《元气骑士》玩家在联机模式中快速刷出想要的挑战因子组合。

## ✨ 主要功能（规划中）

- 🎯 **智能匹配**: 自动识别已刷新的因子，判断是否命中目标配方
- 🔄 **自动刷新**: 未命中时自动点击刷新按钮，直到刷出想要的组合
- 📋 **配方管理**: 支持保存多套因子配方，一键切换
- 🧩 **智能校验**: 实时检测配方冲突、不可能组合，并提供自动纠正建议
- 🎲 **概率估算**: 显示当前配方的命中率和期望刷新次数
- 🔗 **口令码分享**: 通过口令码快速分享和导入配方
- 🐛 **调试模式**: 显示识别过程和置信度，方便排查问题

## 📐 技术架构

### 核心技术栈

- **语言**: Kotlin 2.2.10
- **UI 框架**: Jetpack Compose + Material 3
- **构建工具**: Gradle 9.6.0 + AGP 9.4.1
- **最低系统**: Android 8.0 (API 26)

### 模块结构

```
KazeFactor/
├── app/                    # Android 应用主模块
│   ├── ui/                 # Compose UI 组件
│   ├── overlay/            # 悬浮窗服务
│   ├── service/            # 无障碍服务
│   ├── engine/             # 自动化引擎
│   ├── capture/            # 屏幕截图
│   ├── vision/             # 图像识别
│   └── data/               # 数据持久化
│
└── core-domain/            # 纯 Kotlin 业务逻辑模块
    ├── model/              # 数据模型（因子、配方、槽位约束）
    ├── rule/               # 规则引擎（冲突检测、自动纠正）
    ├── codec/              # 口令码编解码
    └── [测试]              # 单元测试（可在 PC 上运行）
```

### 识别方案

- **校准**: 通过匹配刷新按钮和骰子图标定位槽位坐标
- **识别**: OpenCV 模板匹配（基于游戏原始图标）
- **稳定性**: 帧差检测，等待动画结束后再识别
- **多分辨率**: 校准时自动计算缩放比例

## 🎮 使用场景

1. 玩家在游戏内进入"联机模式 → 因子配置界面"
2. 在悬浮窗中选择或创建配方（如"超简单因子""刷钱因子"）
3. 点击"开始"，工具自动识别并刷新，直到匹配成功
4. 震动 + 通知提醒，玩家继续游戏

### 环境要求

- Android Studio Ladybug | 2024.2.1+ (支持 AGP 9.4+)
- JDK 17+
- Android SDK API 26~37

### 克隆与构建

```bash
git clone https://github.com/FuturelessWindchan/KazeFactor.git
cd KazeFactor

# 注意：首次构建需要下载依赖，可能需要较长时间
./gradlew build

# 运行单元测试（纯 Kotlin，无需 Android 设备）
./gradlew :core-domain:test
```
